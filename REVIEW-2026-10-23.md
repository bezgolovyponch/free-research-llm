## Suggestions (not done), in order of value

1. **One loop at a time per set of free keys, or a quota-aware scheduler.** Right now the Mac runs the old research's loop and the PC runs v2's loop, both on the same free quotas. Two loops halve each other's speed and raise 429s. First step: when a second loop starts, show "another loop is using the same quotas" with a choice to queue it. A global token-bucket per provider (Groq lists 30 requests a minute per model on the free tier; check the console's Limits page) would let lanes back off before a 429 instead of after.
2. **Teammate Stop.** Anyone with a research link can stop the owner's run or loop. At 10:09 v2's run was stopped by **Stop** with a teammate connected. Suggest: Stop from a share link removes that teammate's lane; only the owner, or the person who started it, stops it for everyone.
3. **Root (Q) trials.** Q was the most-tried target (12 trials, 3 kept). Each one re-rolls the whole research. Suggest limiting Q to one trial per pass, after the piece trials.
4. **Shorter timeouts on slow free providers.** Failed calls that time out wait 120 s (`timeoutMs = 120000` in `src/llm/provider.mjs`) before the fallback. Successful OpenRouter calls averaged about 32 s. A per-tier timeout (fast 45 s, deep 90 s) would cut the waste with little risk.
5. **Remove or hide the free-model coder.** 61% of its calls failed, and ticket C2 never produced a passing change. Claude Code is the implementer that works. Hide the free option unless a model that fits the prompt size is available.
6. **SambaNova.** Its key has no balance, so it is not a free provider for this account. Remove the key or the preset.
7. **Documentation sprawl.** 17 Markdown files at the root. `Improvement_loop_report.md`, `OSS-REVIEW.md`, `LOCAL-GPU-PLAN.md` and `FREE-ROUTING.md` describe past states. Suggest folding what is still true into GUIDE/PROTOCOLS and moving the rest under `docs/archive/`.
8. **Local GPU on this Mac.** `data/llama/` holds a 31 MB llama.cpp Metal build. On an 8 GB MacBook Air local models are not practical; keep the feature for the Windows PC, and consider deleting this build.

## Concept check

- "A model proposes, code decides": the glamping check was the one place where a model decided a gate. It is closed now, including for checks stored before the fix.
- Chats stay in scope: questions about the app asked through a share link are refused instead of being forwarded to the owner's App assistant.
- Results keep a single source of truth: lanes merge only a trial's own pieces onto the latest research, and every keep still passes the same gates.
