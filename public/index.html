Guide

1 · Ask

  1. Click + New research. Write the decision with place, time and money.
  2. Write the expected result: what must exist at the end. Code turns it into checks (item count, live links, value range).
  3. Press Build the tree.

2 · Shape the tree

  1. Outline lists every piece; Map shows the dependency graph. Click a piece to open it in the side panel.
  2. Chat with the piece: "read Golf listings in DE and CZ 2000–4000 EUR", "split by fuel type", "re-research". Your message takes priority over a running loop.
  3. Suggest sub-issues searches first, then proposes; each suggestion shows whether it is quoted from a source.

3 · Research and improve

  1. ▶ Run researches every piece. Colours: grey pending, blue running, green verified, teal supported, amber weak, red unsupported.
  2. Improve loop changes one piece at a time and keeps a change only if the measured score rises. Its reports appear in the chat.
  3. Report holds the verdict, the expected-result checks and every delivered link with its live / in-range check.

What the grades mean

verified: all checks pass with 2+ independent sources or data read by code · supported: all checks pass · weak: an uncited number, an evasive answer or a reviewer objection · unsupported: no answer, an invented source or link, or arithmetic that does not recompute.
