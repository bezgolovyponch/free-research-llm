How to get an issue solved: exact steps

A · One-time setup (5 minutes)

  1. Create free keys: at least Gemini (aistudio.google.com/apikey), Groq (console.groq.com/keys) and LangSearch (langsearch.com) and Tavily (app.tavily.com) for web search. Better: also Mistral, Cerebras, NVIDIA, Exa and Jina; unlimited search: run ./searxng.command. The full verified list is in KEYS.md.
  2. Double-click keys.command in the app folder and paste each key when asked. Keys go into the macOS Keychain, not into a file. You can also paste a key in Setup for the current session only.
  3. Start the app: 
    cd free-research-llm && npm start
    Then open http://127.0.0.1:4600. Mac: double-click start.command.

B · Solve an issue

  1. Ask: pick the problem type (or Auto). Write the decision in one or two sentences with where, when, how much, what counts as success. Fill the detail fields. Attach a CSV if you have one.
  2. Click Research it. The Tree tab shows the question decomposed into 3–6 drivers, each with 2–4 sub-questions, plus dependencies such as "margin needs both prices".
  3. Watch the nodes change colour: grey (pending), blue (researching), then the grade. Each leaf gets web sources, an answer with cited claims, a machine-recomputed calculation, and an independent reviewer pass. A leaf that fails the checks is retried once on the stronger model.
  4. Fix the tree where it is wrong. Click a node to edit its question, add a sub-question, break it down further or re-research it with a hint (e.g. "use otomoto.pl prices, 2026"). Only that branch is redone.
  5. Read Report: verdict (GO / NO-GO / GO-IF), key numbers, scenarios, what flips the decision, risks and next steps. Download it as Markdown.
  6. Trust amber and red nodes less. Use them as your to-do list: get the missing data, upload it as CSV, or re-research with a better hint.

D · What the grades mean

verified: all checks pass and the claims are cited from 2+ independent sources (or your data). supported: all checks pass, fewer independent sources. weak: an uncited number, a reviewer objection, or overconfidence. unsupported: no answer, an invented source, or arithmetic that does not recompute. Taxes and legal answers are research, not advice: confirm them with a licensed advisor before acting.
